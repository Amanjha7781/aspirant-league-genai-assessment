# AI tool disclosure

OpenAI Codex was used as a coding assistant in this project to plan the architecture, draft application modules, tests, synthetic sample-generation code, evaluation scripts, and documentation. Codex also ran the listed commands and helped debug failures. The developer should review and understand the implementation before submission; this work should not be represented as unaided authorship.

The ten invoice PDFs and two policy text fixtures were generated locally from synthetic data. No employer assessment PDF, personal records, resumes, or third-party documents were sent to an LLM. The assessment PDF was read locally to map requirements. The OpenAI-compatible LLM client was initially unconfigured; update 22 Nov 2026: a real endpoint (gemini-3.5-flash-lite, free Google AI Studio key) was then configured and real generation/extraction calls were made for the evaluations and demo. Only synthetic sample documents were sent to the provider; no employer assessment PDF, personal records, resumes, or third-party documents were sent. The MiniLM embedding model was downloaded from Hugging Face and runs locally; document content used for embedding is not sent to that provider.


Update 22 Nov 2026: a second AI assistant (Instinct) extended the evaluation scripts (added the model-backed RAG answer stage, fixed a double-counted accuracy denominator, added bounded retry/pacing), configured a free Google AI Studio Gemini key (`gemini-3.5-flash-lite`) as the OpenAI-compatible endpoint, ran the model-backed evaluations and the recorded demo, and updated these documents. All reported metrics are real recorded model outputs from those runs; failed and retried calls are counted in the artifacts. The developer should review and understand these changes before submission.
